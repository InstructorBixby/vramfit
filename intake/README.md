# intake

One JSON file per machine, holding a single measurement or a list.
Validated by the pipeline against
`vramfit/schema/ledger-entry.schema.json`; `docs/measuring.md` says
what each field is for and why it is required rather than suggested.

Rows here are the source for `docs/measured.md`. Nothing in this
directory affects the predictions -- it is evidence about them, and the
only evidence I have for the machines I do not own.
